# ADR-001：P0 编辑核心与 Windows 外壳

日期：2026-10-20。状态：**P0 主路径和原生补验已有结果，最终独立审查收口中；不进入 P1。**

## 背景与决策

保留 Electron + React/TypeScript + 固定 Excalidraw `e1b7aacb356a492aa1e0fc6eb57b8896124027f0`，使用一个场景、一套关系和一套历史。GazBoard v4.9.4 仅作机制、反例和局部纯逻辑参考；本轮没有复制其源码或引入运行依赖。

该选择基于已运行的输入控制、关系/历史、离线资源和桌面证据，不以框架名称或已投入时间判定优劣。产品 D01–D23 不因实现而改写。完整依据：[技术设计](../superpowers/specs/2026-10-19-drawingboard-technical-design.md)、[P0 证据](../validation/p0-evidence.md)、[GazBoard 评估](../research/2026-10-19/gazboard-fit-gap-and-adaptation-assessment.md)。

## 实际接入与维护成本

- `SmartPenLayer` 在父容器捕获智能笔输入，core 设为 public custom tool，避免同一笔被内置工具二次处理。预览在临时 SVG 层，松手通过 Adapter 只提交一次。
- 命中层区分普通内部、边框、已有文字/图片及选择控制点；移动/缩放和关系更新交给原生 selection。三类双击进入真实 textarea，IME 组合优先。
- `connection-policy` 构造 Excalidraw 原生绑定和反向引用，已有图形后连线；不建立 GazBoard connector 或第二套历史。
- 保留 provenance 于 customData，实际编辑器序列化往返；完整恢复动作不在 P0 范围。
- 唯一 vendor 补丁为 `ExcalidrawFontFace.ts` 配置本地资源时不附 CDN 回退。没有修改上游大型 App.tsx/私有输入处理。
- 构造/识别仍依赖 `@excalidraw/element` / `@excalidraw/math` 固定源码内部包，不能称为稳定 SDK、零升级成本。升级时复跑输入、绑定、历史、字体和文件往返用例。
- Electron 主进程持有窗口、托盘、全局快捷键、保存对话框与 PDF 打印。preload 仅暴露限定命令，隔离/sandbox 开启，未开放任意 fs/IPC。

## P0 决策门槛

| 门槛 | 当前结论 | 依据/限制 |
| --- | --- | --- |
| 原迹/停顿预览/慢画/单笔 | 自动化 PASS | 计时纯逻辑、真实分类器和窗口测试分开；合成不代表真人总体识别率 |
| 边框/内部/双击/控制点 | 主路径 PASS | 原生框内绘制/边框移动已实测；独立文字再编辑的原生 WYSIWYG 抢焦点问题通过公开工具切换修复，覆盖再编辑与拖动；待最终全套与审查 |
| 中文 IME | 原生补验 PASS | Microsoft 拼音候选、Esc、Ctrl+Enter、选字、Enter 换行；DOM 模拟另有回归 |
| 绑定跟随/单次撤销/来源往返 | P0 自动化 PASS | 线端绑定与箭头规则不引入另一模型；完整关系生命周期/恢复仍在 P1 |
| 本地离线字体/图片 | app offline 测试 PASS | 本地 file 构建重载、零 HTTP 资源；未关闭主机网络，不等于安装验收 |
| 全局唤出/冲突/退出释放 | 原生与自动化 PASS | 计算器焦点下实际按键恢复 7 对象；另进程实际抢占/退出后注册检查 |
| 基本 PDF | PASS | 真实输出后渲染，中文、连线、图片同页完整 |
| 性能暂定门槛 | 核验中 | 修正口径首轮约 23ms/1.75s/17.7ms；最终构建 Hash 与隐藏后台样本须落证据 |
| 独立审查 | 待完成 | whole-branch fresh-context review 后处置重要问题，再给最终结论 |

## 性能测量修订

旧 2.57s 是包含约 5MB Playwright 数据参数传输的历史口径。定向剖析将驱动传输与本地测试进程读文件区分；后者更接近产品恢复的数据入口。新的基准依然从外部启动计时，包含 CDP 连接、本地合成场景读取、解码/帧和实际笔画提交；并未通过扣减估算值冒充实测。

这只是一份 P0 参考场景测量，不等于已实现 P1 持久化、不等于开机冷缓存或安装后表现。物理快捷键只验功能，自动化 show 到输入测量不含物理键派发。保留原目标 300/2000/32ms，未为了适配结果放宽阈值。原始样本和 Hash 见 [测量 JSON](../validation/assets/2026-10-20-performance.json)。

## 后果与禁止外推

只允许在完整 P0 门槛、审查收口后把该核心视为后续阶段候选；当前用户明确不进入 P1。没有用户操作手感认可、市场差异证明、安装包、发布或完整许可审计结论。

日常可靠保存/恢复、最近列表、完整原迹恢复、命名区域、风格、展示和可编辑文件仍未交付。P0 完全退出会丢失画布，README 与窗口状态文案明确。不将这些后续能力列作本阶段已经实现。

若后续适配迫使复制大型 App、引入第二套场景/历史或牺牲产品输入规则，则重新打开本 ADR 并给出失败证据，优先比较替代核心；不靠静默改变需求继续。
