# DrawingBoard

一个面向 Windows、以鼠标和键盘为主的快速画板：随时唤出，在自由画布上绘制草图、整理结构与关系、组合页面布局。

目前处于产品与技术方案设计阶段，尚未开始应用开发。`DrawingBoard` 为项目代号，正式产品名称尚未确定。
